# Dataset

`autoscout_car_sales.csv` contains 15,915 AutoScout24 car listings from 2019,
covering nine models and 23 columns. The prediction target is `price` in euros.

Source: [AutoScout24 Car Sales 2019 on Kaggle](https://www.kaggle.com/datasets/duygujones/autoscout24-car-sales2019)

The dataset publisher labels it Apache 2.0. Keep attribution and verify the
upstream terms before redistributing the data outside this project.
